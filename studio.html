Test Run Behaviour

Close tab after test run When off, the tab stays open after each test so you can inspect the result.

Display

Verbose fragment descriptions When on, fragment descriptions show each action on its own line with chain branch detail. Useful for reviewing what a fragment does and for auto-compose. When off, descriptions are single-line summaries.

Authoring

Fragment length cap Hard limit on actions per fragment. Long fragments are more brittle (every action is a possible failure point) and harder to compose from strategies (reuse benefits from short, focused units). Default 7.
Unlimited length (advanced) Disable the hard cap. The authoring panel will still warn when a fragment exceeds 7 actions, but won't block you. Use only when you've already chosen to accept the stability and composability tradeoffs.
Observation extract cap Hard limit on extracts per Observation. Each extract is one read from the page; bundling many in one Observation is convenient but every extra extract is another selector that could go stale. Default 7.
Unlimited extracts (advanced) Disable the hard cap on extracts per Observation. The authoring panel will still warn past 7 extracts, but won't block you. Use only when you've already chosen to accept the maintenance tradeoffs.
